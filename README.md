# Tag list

Мобильное PWA-приложение для работы с КИП-тегами, заданиями и страницами.

## Структура

- `index.html` — интерфейс приложения
- `css/app.css` — стили
- `js/app.js` — инициализация и обработчики
- `js/storage.js` — хранение и страницы
- `js/tags.js` — теги и выборка
- `js/export.js` — экспорт и отчёты
- `js/ocr-utils.js` — распознавание и обработка текста
- `js/import.js` — текстовый/Excel импорт
- `js/ui.js` — шрифты, темы, подтверждения
- `js/ocr.js` — OCR, загружается только при использовании фото/OCR
- `sw.js` — PWA/offline cache
- `manifest.webmanifest` — PWA manifest
